# PocketCoffea

[PocketCoffea](https://pocketcoffea.readthedocs.io/) is a High Energy Physics (HEP) analysis framework based on [Coffea](https://coffeateam.github.io/coffea/). It is a core tool heavily utilized across our physics analyses for efficiently processing NanoAODs using modern columnar analysis paradigms.

## Key Features
- Columnar analysis powered by `awkward-array` and `coffea`.
- Scalable workflows running seamlessly on CMS computing clusters via HTCondor, Slurm, or Dask.
- Configurable processor structures, systematic variations, and categorization logic.
