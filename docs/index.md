# CMS PHY DET Analysis Hub

Welcome to the CMS PHY DET Analysis documentation hub.

This site is the central workspace for project documentation, daily development logs, project wikis, technical notes, meeting records, and AI-assisted research/development workflows.

## Main Areas

### Projects

Each project has its own directory, including:

- Overview
- Daily log
- Wiki
- Meeting notes
- Resources
- Open questions
- Development roadmap

Go to: [Projects](projects/index.md)

### Daily Development Logs

Daily logs record what was changed, what was learned, what problems appeared, and what should be done next.

Go to: [Daily Logs](logs/index.md)

### Shared Wiki

The shared wiki collects reusable knowledge about CMS analysis, EOS storage, GitLab workflows, software environments, documentation conventions, and computing tools.

Go to: [Wiki](wiki/index.md)

### Templates

Templates define a consistent structure for new projects, logs, meetings, and technical notes.

Go to: [Templates](templates/project-template.md)

### AI-Assisted Development

This site is designed to be built and maintained with agentic AI assistance. AI agents should help create pages, summarize logs, update project status, generate documentation, and maintain consistency.

Go to: [AI Rules](ai/agent-rules.md)

## Suggested Daily Workflow

1. Create or update the daily log.
2. Record what was developed today.
3. Add problems, decisions, and next steps.
4. Link new knowledge to the project wiki.
5. Ask the AI assistant to summarize and clean the page.
6. Commit changes to Git.
7. Publish the updated static site to EOS.

## Site Philosophy

This website should not only show final results. It should preserve the full development process:

- what was tried,
- what failed,
- what worked,
- why decisions were made,
- what should be done next.

Over time, it should become the long-term memory of the analysis and development work.
