# CMS Run3 HH bbWW

This project focuses on the measurement and search for Higgs boson pair production (HH) in the semi-leptonic and fully leptonic $bbW^+W^-$ final states using CMS Run 3 collision datasets.

## Objectives
*   Search for resonant and non-resonant HH production in the bbWW channel.
*   Optimize jet reconstruction, b-tagging configurations, and tau/lepton vetoes for the Run 3 environment.
*   Model major backgrounds (specifically $t\bar{t}$ and single-top production) using high-precision Monte Carlo samples.
