# Particle Transformer

This project focuses on using Particle Transformer models and machine learning optimization techniques to enhance particle reconstruction, track fitting, and jet clustering algorithms at CMS.

## Objectives
*   Develop high-performance Transformer architectures tailored for irregular particle physics data structures.
*   Optimize model execution speed and memory footprint using quantization and pruning techniques for HL-LHC trigger systems.
*   Incorporate machine learning based calibration and regression directly into the reconstruction chain.
