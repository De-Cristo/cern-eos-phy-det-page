# CMS Run3 VHbb Differential Measurement

This project focuses on the Higgs boson measurements in the VH (Vector boson + Higgs) production process, where the Higgs boson decays into a bottom quark pair ($H \rightarrow b\bar{b}$), using CMS Run 3 collision data in the Simplified Template Cross Sections (STXS) stage 1.3 framework.

## Objectives
*   Perform differential measurements of VH production cross-sections in exclusive STXS stage 1.3 bins.
*   Optimize bottom-quark jet reconstruction, energy regression, and b-tagging calibrations for Run 3.
*   Extract signal strengths, coupling modifiers, and place constraints on effective field theory (EFT) parameters.
