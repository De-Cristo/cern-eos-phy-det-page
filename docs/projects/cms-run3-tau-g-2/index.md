# CMS Run3 Tau g-2

This project focuses on the measurement of the anomalous magnetic moment of the tau lepton ($a_{\tau} = (g_{\tau}-2)/2$) using CMS Run 3 collision data, utilizing ultra-peripheral PbPb collisions or other high-precision channels.

## Objectives
*   Measure the tau $g-2$ anomalous magnetic moment using Run 3 datasets.
*   Optimize event selection algorithms and kinematic reconstruction for tau lepton decays.
*   Evaluate systematic uncertainties associated with photon fluxes and lepton reconstruction.
