LLM-based intelligent agentic pipeline to harvest, aggregate, and analyze Data Quality Monitoring (DQM) logs, hardware state configurations, and shift operations logs for the CMS **MIP Timing Detector (MTD)**.

## Objectives
*   **Automated Log Harvesting**: Retrieve real-time DQM flags, trigger logs, and hardware config tables from MTD runs.
*   **Anomalous Noise Analysis**: Utilize LLMs to identify correlated noise patterns, hot channels, and low-voltage trips from raw monitoring streams.
*   **Shift Assistance**: Generate automatic, plain-English shift handovers, runs summaries, and anomaly alerts for MTD operations teams.
